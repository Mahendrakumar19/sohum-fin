# Sohum Fintech Solutions LLP Website --- Project Documentation

This documentation pack defines the proposed marketing website for Sohum
Fintech Solutions LLP, based on the client-provided reference
screenshot.

## Documents

-   `PRD.md` --- product requirements, goals, scope, users, and
    acceptance criteria.
-   `DESIGN.md` --- visual direction, layout, components, responsive
    behavior, and accessibility.
-   `TECH_STACK.md` --- recommended technologies and implementation
    conventions.
-   `ARCHITECTURE.md` --- frontend/backend boundaries, routing, data
    flow, and security.
-   `CONTENT.md` --- page structure and draft website copy.
-   `FEATURES_AND_USER_FLOWS.md` --- detailed features and user
    journeys.
-   `API_SPEC.md` --- optional lead API contract for a future backend
    implementation.
-   `SEO_AND_ANALYTICS.md` --- search optimization, metadata, analytics,
    and performance.
-   `TESTING_QA.md` --- testing strategy and launch acceptance
    checklist.
-   `DEPLOYMENT.md` --- environment setup, deployment, domain, and
    release steps.
-   `SCOPE_AND_ESTIMATE.md` --- proposed scope, exclusions, timeline,
    and indicative quote.
-   `OPEN_QUESTIONS.md` --- client decisions and information that must
    be confirmed.

## Project summary

Create a responsive, professional fintech marketing website that
presents investment and loan services, explains the company's value
proposition, provides a working EMI calculator, and converts visitors
into enquiries.

## Important assumptions

1.  The screenshot is a visual reference, not proof that every displayed
    company detail is verified.
2.  Phone, email, address, partner logos, legal wording, and company
    claims must be confirmed by the client before launch.
3.  The initial scope is a marketing website and lead-generation
    experience, not a lending, investment-trading, insurance-purchase,
    or financial-advice platform.
4.  The proposed ₹55,000 development estimate is indicative and excludes
    applicable GST, hosting/domain costs, paid services, and features
    outside the agreed scope.
5.  No bank/NBFC integration, user account system, document collection,
    or admin CRM is included in the base scope.

## Suggested implementation baseline

Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui, Lucide
React, React Hook Form, and Zod. A database/backend is optional unless
enquiry persistence or admin management is confirmed as a requirement.
